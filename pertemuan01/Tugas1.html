Identitas & Program Studi

Saya terdaftar sebagai mahasiswa aktif pada program studi Teknik Informatika. Bidang ini mempelajari cara merancang, membangun, dan memelihara sistem berbasis komputer, mulai dari algoritma dan struktur data hingga pengembangan perangkat lunak secara utuh.

Minat

Minat saya berada di seputar pengembangan perangkat lunak, khususnya pada bagian logika program dan penyusunan dokumentasi teknis yang rapi. Saya juga tertarik mempelajari bagaimana struktur informasi yang baik dapat membuat sebuah halaman web lebih mudah dipahami.

Tujuan Belajar

Melalui tugas praktikum ini, tujuan saya adalah memahami dengan benar hierarki elemen HTML — kapan menggunakan heading, paragraf, serta penekanan teks — sebagai fondasi sebelum masuk ke tahap perancangan tampilan yang lebih kompleks.
